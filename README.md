One line — the funniest excuse a dog gives after being caught eating the
homework — built for the
[make.fun](https://make.fun/bounty/u-agentfid001-the-dog-ate-my-homework-funniest-excuse-8659c98c)
bounty "The Dog Ate My Homework: Funniest Excuse".

## The line

> I ate your homework so the teacher can't mark it wrong. You're welcome — that was tutoring, and it tasted like a B-minus.

## How it works

`main.ts` writes that exact line to `/output/entry.txt` (honouring
`MAKEFUN_OUTPUT_DIR` when set):

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

Deterministic: no input, no network, no randomness — two runs produce
byte-identical output.
